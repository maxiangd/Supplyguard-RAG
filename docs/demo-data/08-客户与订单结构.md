# 客户结构与订单模式

> 整理时间：2026-10-25｜来源：公开报道与行业资料｜用途：SupplyGuard 演示数据

## 主要客户类型

- 海外整车厂：特斯拉、宝马、梅赛德斯-奔驰、大众、现代、Stellantis、沃尔沃等。
- 国内整车厂：理想、蔚来、极氪、问界等新势力与传统车企新能源品牌。
- 储能客户：海外储能系统集成商与电力项目开发商。
- 技术授权：通过 LRS（许可、特许权使用费、服务）模式向福特等海外车企输出磷酸铁锂技术。

## 订单与合作模式

- 长期框架协议：与主流车企签订多年供货框架，按车型定点开发。
- 合资建厂：匈牙利工厂服务欧洲车企本地化需求，西班牙工厂与 Stellantis 合资。
- 技术授权：不建厂、不持股，按授权与服务收费，规避重资产与地缘风险。

## 客户集中度

公司未在公开材料中逐家披露客户份额。行业普遍认知是：前五大客户占比较高，单一客户订单波动会显著影响某条产线的排产。整车厂近年推进"去宁化"、二供三供策略，也是客户结构的潜在变化因素。

## 对财务的影响

- 海外客户占比提升，有利于平滑国内价格战带来的单价下行。
- 合资与授权模式下，收入确认节奏与自建产能不同，需单独跟踪。
- 客户集中度高时，单一客户的召回、停产或切换供应商都会造成收入缺口。

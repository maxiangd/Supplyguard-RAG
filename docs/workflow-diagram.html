完整时序 LangGraph 节点 + 外部操作

1
Phase 1 · graph.invoke(initial)
LangGraph 连续执行 retrieve → graph_analyze → review → build_context
产出 state：hits · graph_paths · entities · messages · review_passed_*
⏸
中断 ① · interrupt_before="assess_risk"
图暂停 👈 路由处理器接管
2
SSE 事件 · yield hits + graph
前端展示检索证据与图谱路径
3
SSE 流式生成 · yield reasoning + delta
LLM 逐 token 生成回答，前端实时渲染
deepseek-reasoner 额外透传 reasoning_content
4
Phase 2 · Command(update={answer}) 恢复图
LLM 回答注入 state，图继续执行
5
assess_risk 节点执行
调 LLM 二次评估风险等级 → 写入 state.risk_level
6
条件路由 · _build_conditional_edge
risk_level == "HIGH" → approval_gate  |  其他 → finalize
↓
非 HIGH 路径 → finalize → END
直接收尾，不触发审批。SSE 推送 risk 事件后 done
⏸
中断 ② · interrupt_before="approval_gate"
⚠ 仅 HIGH 风险路径到达此处
7
路由处理器 · 创建审批单 + yield risk + approval
DB 写入 approvals 表 + audit_logs 表
前端收到 approval 事件，展示「已提交审批」提示卡
⏳
阻塞等待 · threading.Event.wait(300s)
SSE 线程休眠，等待管理员调用 POST /api/chat/decision/{id}
8
Phase 3 · Command(resume="approved") 恢复图
图继续执行 approval_gate → finalize → END
9
SSE 事件 · yield done
前端展示最终结果，流程结束
